[**Live Demo**](https://agentic-fraud-sentinels.streamlit.app/)

#### [Solar Wind Forecaster](https://github.com/aryan11singh/Solar-Wind-Forecaster)
**Engineered an enterprise-grade ML pipeline** that forecasts geomagnetic storms (SYM-H index) using high-resolution solar wind telemetry. Implemented Scikit-learn Gradient Boosting models trained on NASA solar data for real-time space weather prediction. Built an end-to-end Streamlit interface for visualization and forecasting. [**Live Demo**](https://solar-wind-forecaster.streamlit.app/)

#### [Quiz Management System](https://github.com/aryan11singh/Quiz-Management-System)

Designed data pipelines for automated scoring, weakness identification, and performance trend analysis. [**Live Demo**](https://quizmanagementsystem.streamlit.app/)

#### [Space Weather Sentinel](https://github.com/aryan11singh/SPACE-WEATHER-SENTINEL)
**Architected a real-time space weather monitoring platform** that tracks solar activity, geomagnetic disturbances, and radiation events. Integrated NASA DONKI and NOAA APIs for live data feeds. Deployed on Vercel for high-availability access. [**Live Demo**](https://space-weather-sentinel.vercel.app)

#### [DPI Engine](https://github.com/aryan11singh/DPI-Engine)
**Built a C++17 Deep Packet Inspection engine** for reconstructing TCP/UDP data streams. Engineered multi-threaded architecture for parallel processing and efficient traffic classification via TLS SNI and HTTP Host inspection. Designed for gigabit-speed data ingestion with minimal contention.
