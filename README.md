### 🚀 Featured Engineering Projects

#### [Synctax](https://github.com/aryan11singh/synctax)
**Architected a browser-based real-time collaborative code editor** with **Yjs CRDTs**, **Monaco**, and **WebSockets**, achieving sub-100ms multi-user synchronization and offline-reconnect state merging. Built an isolated execution engine using disposable **gVisor (runsc)** sandboxes and **BullMQ**, enforcing cgroup v2 resource limits and seccomp profiles against exploits. Backed by **Fastify 5**, **Prisma 7**, **PostgreSQL 16**, and **Redis 7** with automated **Claude AI** code review and an online judge.

#### [Your-Own-AI](https://github.com/aryan11singh/Your-Own-AI)
**Engineered a custom C++ vector database** implementing **HNSW** multilayer graph indexing for $O(\log N)$ approximate nearest neighbor search alongside KD-Tree and brute-force benchmarks. Built a local RAG pipeline integrating **Ollama** (`nomic-embed-text`, 768D) with Llama 3.2, featuring live **2D PCA** dimensional projection and an embedded multithreaded REST API.

#### [DPI-Engine](https://github.com/aryan11singh/DPI-Engine)
**Built a high-throughput C++17 Deep Packet Inspection engine** parsing raw PCAP streams and reconstructing TCP/UDP flows via 5-tuple tracking. Implemented Layer-7 protocol identification extracting **TLS Client Hello SNI** and HTTP Host headers for traffic classification, powered by multithreaded hash-based packet load balancing and an atomic fast-path cache.

#### [DishPatch](https://github.com/aryan11singh/DishPatch)
**Engineered a stateful multi-turn AI restaurant ordering & kitchen lifecycle agent** built with **LangGraph**, **Groq**, **FastAPI**, and **Streamlit**. Leveraged structured Pydantic outputs for dynamic intent parsing, real-time inventory validation, fault-tolerant kitchen failure simulation with human-in-the-loop fallback, and conversation state management via MemorySaver.

#### [Agentic Fraud Sentinel](https://github.com/aryan11singh/Agentic-Fraud-Sentinel)
**Developed an AI-powered fraud detection system** leveraging an agentic AI architecture for intelligent, multi-step transaction analysis. Designed autonomous agent workflows to detect, classify, and flag suspicious financial transactions in real-time, deployed as an interactive Streamlit dashboard. [**Live Demo**](https://agentic-fraud-sentinels.streamlit.app/)

#### [Solar Wind Forecaster](https://github.com/aryan11singh/Solar-Wind-Forecaster)
**Engineered an enterprise-grade ML pipeline** forecasting geomagnetic storms (SYM-H index) from NASA solar wind telemetry. Implemented Scikit-learn Gradient Boosting models for real-time space weather prediction, paired with an interactive Streamlit visualization interface. [**Live Demo**](https://solar-wind-forecaster.streamlit.app/)

#### [UPI-Mesh](https://github.com/aryan11singh/UPI-Mesh)
**Developed an offline-first Python payment backend** with SQLite and containerized deployment. Engineered a Zero-Trust authorization pipeline with server-side PIN hash validation and hybrid RSA-2048/AES-256-GCM encryption for payments settled over a simulated Bluetooth mesh.
